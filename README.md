# Student Performance Prediction System

A machine learning project that predicts a student's final grade and pass/fail result.

## What it does
- Cleans and encodes the student performance dataset
- Visualises study time, absences, failures and grades
- Trains linear regression (final grade) and logistic regression (pass/fail)
- Includes an interactive prediction tool

## Tools
Python, pandas, scikit-learn, matplotlib, seaborn

## How to run
Open the notebook in Jupyter or Google Colab and run all cells.# student-performance-prediction
Machine learning project predicting student grades and pass/fail using Python and scikit-learn
